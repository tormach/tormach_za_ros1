## `za6_robot` package

This package wraps the `za6_moveit_config` package, which is
auto-generated by the `moveit_setup_assistant`, and adds interfaces to
the UI and hardware packages.

This should be the only package that references the MoveIt config
package, and any local changes to auto-generated configuration should
be overridden here.  Keeping that package pristine preserves the
ability to re-run the assistant without clobbering local changes.

### Running a UI

The PathPilot UI is run with the `devel_scripts/start_robot_ui.py za6`
script.

Run plain `rviz` with HAL as follows:

```
# Start the ROS machinery
roslaunch za6_robot moveit_planning_execution.launch \
    tool:=none \
    hal_debug_output:=false \
    hal_debug_level:=5 \
    mastering:=false \
    sim:=true \
    ros_wait_timeout_s:=30
rosservice call hal_402_drives_mgr start
```

Run headless as follows:

```
# Start the ROS machinery
roslaunch za6_robot moveit_interpreter.launch \
    tool:=none \
    hal_debug_output:=false \
    hal_debug_level:=5 \
    mastering:=false \
    sim:=true \
    ros_wait_timeout_s:=30
# Enable drives (other commands:  stop=1; home=3)
rostopic pub -1 /hal_io/state_cmd std_msgs/UInt32 2
# (Equivalently:  halcmd sets state_cmd 2 )
# Load a program file
rosservice call /robot_command/load_program \
    ~/nc_files/robot_programs/example_program.py
# Run the program; see src/robot_command_msgs/srv/RunCommand.srv
rosservice call -v /robot_command/run_command 2 # COMMAND_START
```
